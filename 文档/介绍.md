引用.包导入("包名", "1.2.0");

包目录结构：
包/包名/atp.json
包/包名/入口.at

atp.json 格式：
包名: 网络请求
版本: 1.2.0
入口: 入口.at

atp 命令：
atp create 包名
atp install 包名 [仓库目录|URL]
atp install
atp update 包名 [仓库]
atp list [仓库目录]
atp search 关键字 [仓库目录]
atp uninstall 包名
atp pull <url|url.zip> 包名
atp publish 包名 [源目录]

示例：
引用.包导入("网络请求");
引用.包导入("工具");

设 r = 网络请求.发送("http://example.com");
打印("返回: " + r);
