# AtUnity — 用 Atlanage 写的"at版 Unity"迷你 2D 游戏引擎

AtUnity 是纯 **Atlanage 语言**(本仓库 `c-atlanage/` 编译器)实现的迷你 2D 游戏引擎,
架构对齐 Unity 的核心概念:**游戏对象 / 组件(部件)/ 场景 / 刚体 / 碰撞器 / 相机 / 渲染器 / 时间 / 输入**。
底层零 C 运行时改动,完全构建在现有 AUI 图形库(`atl_ui.c` + `测试/lib/atl_ui.at`)之上。

## 一、架构与 Unity 概念对照

| AtUnity | Unity | 说明 |
|---|---|---|
| `类 游戏对象` | GameObject | 位置(x,y/角度/缩放)+ 激活 + 标签 + 部件列表 |
| `类 组件` | Component | 挂到对象上的行为模块,可覆盖 更新/物理更新/渲染/碰撞事件 |
| `类 场景` | Scene | 对象容器 + 生命周期(进入/更新/渲染/退出)+ 碰撞检测 |
| `类 引擎` | Application | 窗口 + 主循环(输入→更新→物理→碰撞→渲染)+ 场景切换 |
| `类 刚体` | Rigidbody | 速度/重力/摩擦,每帧推进对象位置 |
| `类 盒碰撞器 / 圆碰撞器` | Box/Circle Collider | AABB / 圆 碰撞判定,命中触发 碰撞事件 |
| `类 精灵渲染器 / 文本渲染器 / 形状渲染器` | SpriteRenderer / TextMesh / 图元 | 绘制组件,中心对齐,跟随相机 |
| 场景.相机x/相机y | Camera | 视口偏移(渲染时所有对象坐标减去相机) |
| `增量()/帧数()/时间缩放()` | Time | deltaTime / frameCount / timeScale |
| `按下()/按住()/鼠标x()...` | Input | 键盘边沿(事件队列)/ 按住(轮询)/ 鼠标 |

## 三、快速开始

编译运行(必须在项目根目录,依赖根目录的 .obj):

```bash
atlc.exe --run 测试/51_引擎_飞机大战.at
atlc.exe --run 测试/52_引擎_AtOS系统.at
atlc.exe --run 测试/50_引擎_冒烟.at
```

手动游玩:把 demo 里 `游戏.设置自动帧数(600)` 改成 `游戏.设置自动帧数(0)`,ESC 退出。

### 最小游戏骨架

```at
引用.文件("lib/atunity/引擎.at")

类 我的场景 继承 场景 {
公开:
    声明 进入(){

        设 球 = 创建 游戏对象;
        球.x = 0; 球.y = 100;
        设 形状 = 创建 形状渲染器;
        形状.设置形状(2);
        形状.设置半径(30);
        形状.设置颜色(图元颜色(255, 64, 64));
        球.添加部件(形状);
        设 碰撞 = 创建 圆碰撞器;
        碰撞.设置半径(30);
        球.添加部件(碰撞);
        添加(球);
        返回值 0;
    };
    声明 更新(dt){

        返回值 0;
    };
};

类 main {
公开:
    声明 运行(){
        设 游戏 = 创建 引擎(800, 600, "我的游戏");
        游戏.设置背景色(颜色深蓝);
        游戏.设置自动帧数(0);
        游戏.启动(创建 我的场景);
        返回值 0;
    };
};
```

## 四、API 速查

### 引擎与场景

| API | 作用 |
|---|---|
| `创建 引擎(宽, 高, "标题")` | 创建窗口(注意用逗号,冒号会被解析成 pair) |
| `游戏.启动(场景)` | 进入主循环(阻塞),ESC/关窗/`请求退出()` 退出 |
| `游戏.切换场景(场景)` | 旧场景退出 + 新场景进入 |
| `游戏.设置背景色(颜色)` / `游戏.设置自动帧数(n)` | 背景色 / 自动演示帧数(0=手动) |
| `场景.添加(对象)` / `场景.清空()` / `场景.对象数量()` / `场景.获取对象(i)` | 对象管理 |
| 场景.相机x / 场景.相机y | 相机位置(直接赋值) |
| 覆盖 进入/更新(dt)/渲染/退出 | 子类生命周期;渲染在清屏后、对象渲染前 |

### 游戏对象与部件

| API | 作用 |
|---|---|
| `对象.x / 对象.y / 对象.角度 / 对象.缩放` | Transform(直接读写) |
| `对象.激活 / 对象.标签 / 对象.名称` | 激活状态 / 标签(碰撞区分用)/ 名称 |
| `对象.添加部件(部件)` | 把部件加进对象(每帧由场景"附体"挂载) |
| `对象.删除()` | 标记删除,场景每帧开头清理 |
| `对象.碰撞事件(对方)` | 碰撞回调(默认派发给所有部件,可在子类覆盖) |
| `部件.组件启用` / `部件.挂载对象` | 启用开关 / 所属对象(由附体自动设置) |

### 渲染器

| API | 作用 |
|---|---|
| `精灵渲染器.设置精灵("xx.bmp")` | 加载 24/32 位 BMP,中心对齐 |
| `文本渲染器.设置文本/字号/颜色/居中/隐藏` | UI 文本(颜色用 `文字颜色(r,g,b)`) |
| `形状渲染器.设置形状(kind)` | 1=矩形 2=圆 3=线 4=三角形 5=像素 |
| `形状渲染器.设置尺寸(w,h)` / 设置半径 / 设置颜色 / 设置填充 | 图元参数(颜色用 `图元颜色(r,g,b)`) |
| `形状渲染器.设置起点/目标/目标2(x,y)` | 三角形的三个相对顶点 |
| `渲染器.设置隐藏(flag)` | 隐藏/显示 |

### 物理

| API | 作用 |
|---|---|
| `刚体.设置速度(vx,vy)` / 设置重力(g) | 速度(像素/帧)/ 重力(y 向上为负) |
| `盒碰撞器.设置尺寸(w,h)` | AABB(半宽半高) |
| `圆碰撞器.设置半径(r)` | 圆碰撞 |
| 碰撞事件 | 双方对象都会收到 `碰撞事件(对方)`,按 `对方.标签` 区分 |

### 时间 / 输入 / 颜色

| API | 作用 |
|---|---|
| `增量()` / `帧数()` / `时间缩放(v)` | deltaTime(秒)/ 帧计数 / 时间缩放 |
| `按下(键码)` | 按键边沿(事件队列,支持全部 VK:方向键/ESC/空格) |
| `按住("w")` | 按住状态(GetAsyncKeyState,只支持 a-z / 0-9 小写) |
| `鼠标x() / 鼠标y() / 鼠标按下(1\|2) / 鼠标抬起(1\|2) / 滚轮增量()` | 鼠标(中心原点,y 向上;1=左 2=右) |
| `图元颜色(r,g,b)` | 0x00RRGGBB(绘图图元用) |
| `文字颜色(r,g,b)` | COLORREF(文本用) |
| `颜色红/绿/蓝/白/黑/黄/青/紫/橙/粉/灰/深蓝/深绿` | 常用色(图元格式) |
| `键ESC=27 键空格=32 键左=37 键上=38 键右=39 键下=40 键W=87 ...` | VK 键码常量 |
| `读整数(addr,off) / 写整数(addr,off,v)` | 32 位小端内存整数读写(规避 内存.读字节 只读 1 字节) |

## 六、Demo 说明

### 51_引擎_飞机大战.at
- 操作:W/A/S/D 或方向键移动,空格射击,ESC 退出
- 演示:玩家移动/射击冷却、敌机定时生成、子弹×敌机碰撞计分(+10)、敌机×玩家扣命(3 条命+无敌闪烁)、
  得分/生命 UI 文本、对象批量创建与删除

### 52_引擎_AtOS系统.at
- 操作:鼠标左键点击桌面图标或开始菜单打开窗口,拖标题栏移动窗口,点 X 关闭,ESC 退出
- 演示:桌面图标、可拖动窗口(置顶/关闭)、任务栏(开始按钮+系统时钟)、开始菜单(悬停高亮)、
  场景自绘 UI(不依赖游戏对象)与游戏对象(鼠标光标)混用
