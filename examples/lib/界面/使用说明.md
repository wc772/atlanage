# 界面库 — Atlanage M2 控件层(声明式组件树 + 布局 + 样式 + 事件)

界面库是纯 **Atlanage 语言** 资产(AT 类/函数),编译期零改动;与 AtUnity 引擎库(lib/atunity)
同思路,走包/库机制随项目分发。语法胶水(块作用域/当.xxx)由语言层 M2 扩展合成调用。

## 一、快速开始

```at
引用.文件("lib/界面/界面.at")

设 win = GL.窗口.创建(320, 240, "我的应用");
界面.创建(窗口:win){
    行(间距:8, 填充:16){
        列(权重:1){
            标签(文本:"用户名", 字号:16);
            输入框(占位:"请输入用户名", 值:用户名);
            按钮(文字:"登录")[主题.主色*]{
                当.点击{
                    登录(用户名);
                };
            };
        };
        列(权重:2){
            输入框(占位:"密码", 值:密码);
        };
    };
};

每帧{
    GL.清屏(红:10, 绿:10, 蓝:26, 透明度:255);
    界面.渲染(win);
    GL.呈现(win);
};
```

## 三、控件集(M2-a 五件套)

| 控件 | 语法 | 说明 |
|---|---|---|
| 行 | `行(间距:8, 填充:16){...}` | 水平布局:权重子均分剩余宽,固定子按自然宽 |
| 列 | `列(权重:1, 间距:8, 填充:16){...}` | 垂直布局:权重子均分剩余高 |
| 标签 | `标签(文本:"用户名", 字号:16)` | 文本显示(颜色/样式参数已留) |
| 按钮 | `按钮(文字:"登录")[主题.主色*]{ 当.点击{...}; }` | 后缀给 (颜色,填充);块内挂点击事件 |
| 输入框 | `输入框(占位:"...", 值:初始文本)` | 点击聚焦,字符输入,退格删除,`当.输入(值){...}` |

## 四、布局规则(M2-a)

- 坐标系:与 Win32 一致,窗口客户区左上原点,Y 向下(GLen 绘制内部翻转)
- 容器:填充(padding 四边)、间距(gap 子间距)、权重(weight 剩余空间按比例)
- 叶子控件自然尺寸:标签=字符数×字号;按钮=文本+16;输入框=120×字号+12
- 根容器填满窗口客户区(界面.渲染 每帧查 GL.窗口.大小)
- 容器自然高=max(子自然高)+2×填充;自然宽=固定子宽和+间距+2×填充
- 命中测试:后序遍历(后画=在上层),返回最上层命中控件

## 五、事件(M2-a)

| 事件 | 用法 | 触发时机 |
|---|---|---|
| 点击 | `当.点击{...}` | 鼠标左键点击命中控件 |
| 输入 | `当.输入(值){...}` | 输入框字符输入/退格后,参数=当前文本 |

- `当.xxx` 复用监听形态三机制:块包装为 lambda,合成 __控件事件(事件名,回调) 注册到当前控件
- 事件分发在 界面.渲染 内:轮询 GL.事件.轮询(type 1-9 协议)→点击命中→字符/退格→焦点输入框
- 事件回调是独立作用域 lambda:共享数据用全局变量(与监听形态三一致)

## 六、渲染线程(M2 前置任务 4,修复拖动冻结)

```at
声明 渲染循环(){
    GL.设置当前(窗口:g_win);
    循环(线程运行){
        界面.渲染(g_win);
        GL.呈现(g_win);
    };
};

界面.线程模式设置(真);
设 t = 进程.创建("渲染循环");
循环(线程运行){ GL.消息泵(g_win); };
进程.等待(t);
```

- 主线程泵消息(wndproc 入队),渲染线程独占 GL 上下文渲染并出队事件
- 拖动窗口时 Windows 模态循环在主线程,渲染线程不受阻 → 画面不冻结
- 单线程模式(默认)保持 GL.事件.轮询 泵+出队,兼容既有代码
