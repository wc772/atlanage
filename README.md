# Atlanage

Atlanage 是一门全中文编程语言，支持中文关键字、自举编译器、M:N 任务调度器、AUI 图形界面、OpenGL/Vulkan、包管理等特性。

## 使用

AT-V1.exe -exe examples/hello.at
examples/hello.exe
